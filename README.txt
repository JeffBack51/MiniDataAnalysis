# Mini Data Analysis

This project explores Coffee Census and Boulder housing data. The main analysis
looks at bedrooms, above-ground square footage, and property location in the 
Boulder dataset.

## Files

- `MiniDataAnalysis1.qmd`: Code and findings.
- `MiniDataAnalysis1.md`: Rendered report.
- `dat/`: Data files.
- `MiniDataAnalysis.Rproj`: RStudio project.

## How to Run

Open `MiniDataAnalysis.Rproj` in RStudio. Open `MiniDataAnalysis1.qmd` and click
**Render**. Keep the data files in the `dat` folder.
